# Legacy harness (pre-v2.1) - archived 2026-07-02

These are the pre-v2 control/policy docs, preserved verbatim when Local Agent Town
adopted the LLM Workbench v2.1 harness (four control docs: `AGENTS.md`,
`BLUEPRINT.md`, `TASKBOARD.md`, `RUNBOOK.md`). They are history, not a competing
rulebook - do not follow them. The live docs at the repo root govern.

Where their content went during adoption:

| Archived doc | Disposition |
|---|---|
| `ROADMAP.md` | Split: stable direction -> `BLUEPRINT.md` (Direction And Build Order); live queue, blockers, deferred work -> `TASKBOARD.md`; the full Verification Log is preserved here, with the most recent slices carried into the `TASKBOARD.md` Proof Log. |
| `UNATTENDED_WORK_POLICY.md` | Folded into `AGENTS.md` (Long Session Control, Stop And Ask). |
| `BOOTSTRAP_CHECKLIST.md` | Retired - superseded by the harness ADOPTION/GENESIS protocol. |

The former root `AGENTS.md` and `README.md` were rewritten in place into their v2
forms; their prior content is recoverable from git history (pre-adoption commit
`c960722`).
